# Attribution and provenance

This collection contains student coursework adapted from course-provided exercises and starter material. It is a portfolio record, not a claim that every line was independently authored. Exact student/scaffold boundaries are not available for all historical files. PROVENANCE.json records the source filename, course, retained cells, preparation changes, and status. Existing tutorial and assistance attributions remain in code.

Instructional handouts, solution-only files, original datasets, student records, and notebook outputs are not distributed. No blanket license is asserted over third-party scaffolding or datasets. Dataset use remains subject to the original providers' terms.
