# Systems

The interactive CPU scheduling prototype includes round-robin, shortest-process/remaining-time, highest-response-ratio, and feedback options. Its feedback implementation enqueues arrivals prematurely and checks queue membership after removal, so feedback results are not reliable. Historical behavior is retained and no scheduler-output claim is made. C/C++ operating-systems exercises are maintained in the separate C/C++ portfolio.

Only static Python syntax was checked. See the repository [provenance](../PROVENANCE.json).
